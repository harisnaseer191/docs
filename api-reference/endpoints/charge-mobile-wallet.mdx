---
title: "Charge Mobile Wallet"
api: "POST /Gateway/v{version}/Payment/charge-mobile-wallet"
description: "Charge a customer's mobile wallet using a payment token"
---

## Overview

This endpoint allows you to charge a customer's mobile wallet (JazzCash, Easypaisa, etc.) using a previously generated payment token. This is useful for recurring payments or saved payment methods.

## Path Parameters

<ParamField path="version" type="string" required>
  API version (e.g., "1")
</ParamField>

## Request Body

<ParamField body="token" type="string" required>
  Payment token obtained from initiate-token endpoint
</ParamField>

<ParamField body="mobileNumber" type="string" required>
  Customer's mobile wallet number
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to charge (minimum 10)
</ParamField>

<ParamField body="walletProvider" type="integer" required>
  Mobile wallet provider:
  - `1` - JazzCash
  - `2` - Easypaisa
</ParamField>

<ParamField body="billReference" type="string">
  Optional bill reference number
</ParamField>

<ParamField body="description" type="string">
  Payment description
</ParamField>

## Response

<ResponseField name="trxnRef" type="string">
  Transaction reference number
</ResponseField>

<ResponseField name="status" type="string">
  Transaction status (e.g., "Success", "Pending", "Failed")
</ResponseField>

<ResponseField name="message" type="string">
  Response message with additional details
</ResponseField>
