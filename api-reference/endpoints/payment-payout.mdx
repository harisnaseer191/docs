---
title: "Process Payout"
api: "POST /Gateway/v{version}/Payment/process-payout"
description: "Process a payout to a customer's bank account"
---

## Overview

This endpoint allows you to send money (payout) to a customer's bank account using a payment token. Useful for disbursements, refunds, or commission payments.

## Path Parameters

<ParamField path="version" type="string" required>
  API version (e.g., "1")
</ParamField>

## Request Body

<ParamField body="token" type="string">
  Payment token obtained from initiate-token endpoint
</ParamField>

<ParamField body="amount" type="number">
  Payout amount
</ParamField>

<ParamField body="cnic" type="string">
  Customer's CNIC number
</ParamField>

<ParamField body="customerAccountNumber" type="string">
  Customer's bank account number or IBAN
</ParamField>

<ParamField body="customerBankName" type="string">
  Name of the customer's bank
</ParamField>

<ParamField body="customerFullName" type="string">
  Customer's full name as per bank account
</ParamField>

<ParamField body="customerEmail" type="string">
  Customer's email address
</ParamField>

<ParamField body="description" type="string">
  Payout description or purpose
</ParamField>

<ParamField body="billReference" type="string">
  Optional bill or invoice reference
</ParamField>

## Response

<ResponseField name="message" type="string">
  Response message
</ResponseField>

<ResponseField name="trxnRef" type="string">
  Transaction reference number
</ResponseField>

<ResponseField name="status" type="string">
  Payout status (e.g., "Success", "Pending", "Failed")
</ResponseField>

<ResponseField name="paymentIntentId" type="uuid">
  Associated payment intent ID
</ResponseField>

<ResponseField name="estimatedCompletionTime" type="datetime">
  Estimated time when payout will be completed
</ResponseField>
